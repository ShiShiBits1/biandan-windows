# 便单 Windows 桌面版

本项目由 ShiShiBits1 独立维护，是兼容便单的第三方 Windows 客户端。内置便单 MCP 0.4.3，用于授权和同步。[官方 MCP 项目](https://gitcode.com/biandangroup/biandan_MCP)

退出旧版便单后双击新版 `Biandan.exe`。适用于带有 .NET Framework 4.8 或更高版本的 Windows 10/11 x64。登录服务和图标已内置到主程序，授权时会自动准备本机登录服务。

## 登录和体验

- 点击「使用华为账号登录」，在系统浏览器完成授权，客户端随后自动开始同步。浏览器无法唤起时，可点击「复制授权链接」，将链接粘贴到浏览器地址栏打开。完成后可点击「我已授权，检查登录」。
- 点击「先体验一下」可使用本机示例数据。体验数据和云端数据分别保存。编辑现有循环规则和应用中国节假日调休需要登录。
- 云端数据默认每 3 分钟拉取一次。云端清单读到后会立即刷新，待办改动仍按空闲时机上传。在「设置 → 数据与同步」可更改间隔，按 **F5** 可立即同步。新增、拖动和删除先保存在本机，最后一次修改 15 秒后且应用空闲时集中提交。断网后会自动重试。若云端拒绝某条任务改动，同一任务的后续改动按顺序等待，其他任务与手机清单可以继续同步。在「设置 → 数据与同步 → 同步详情」可查看失败原因并重试该条改动。云端缓存和账号凭据使用 Windows 当前用户加密。
- 在「设置 → 数据与同步」可导出完整备份，或单独导出、恢复待同步队列。恢复会合并记录，跳过已识别的重复改动。退出账号时若仍有待同步改动，可以先导出队列。重新授权后，恢复队列需要与原账号现存的云端记录核对。

## 便单小助手

点击顶部搜索图标左侧的对话图标，打开「便单小助手」并向本机 Codex CLI 提问。需使用 ChatGPT 账号登录 Codex CLI。电脑上的 Codex 桌面版或 CLI 可自动发现，也可在页面选择 codex.exe。若选项不可用，请更新本机 CLI。

可按需勾选附上近期待办。小助手返回的草稿需要点击「添加待办」才会写入。

## 日历与周计划

- 在「日历视图」切换「月历」或「周计划」。周计划从周一开始，可浏览前后各周或回到今天。
- 从「待安排」把任务拖到周计划的时段，任务会先保存在本机。双击空时段可新建待办并预填日期和时间。
- 已排期的单次待办可以拖到新的时段，保留任务时长，包括跨午夜的时段。拖到日期标题只更改日期。任务原有的时间提醒保持原日期及时刻，如需跟随改期，可在待办详情中调整。登录并连接云端后，移动循环任务的某一次需要确认，确认后该次成为独立待办。

## 四象限和看板

待办快录和四象限移动会先显示本机结果。等待上传时仍可继续操作，重新提交同一条快录会沿用原有创建编号。

- 从左侧菜单打开「四象限」。拖动卡片或使用卡片菜单切换重要、紧急标记。循环待办的优先级应用于整个系列。
- 「任务看板」分为待办、进行中和已完成，可按清单筛选。进行中卡片显示子任务或次数进度。支持拖动或通过卡片菜单移动。完成、撤销完成会更新真实任务状态，手动设置的进行中标记保存在本机。
- 两种视图都可按今天、最近七天或全部筛选，也可在搜索框按标题、备注和子任务筛选。

## 沉浸式光感

1.4.0 默认启用沉浸式光感。窗口顶缘、侧栏和浮层随当前主题换色。指针靠近任务卡边缘或手指按下时，接触点附近会亮起。打开任务的更多菜单、全局搜索或便单小助手，可看到浅色磨砂质感的浮层。周计划拖动时，目标日期或时段会高亮，时间格还会预览新的开始时刻。

## 桌面操作

- 在「桌面小组件」或系统托盘菜单打开桌面日历和桌面待办。拖动小组件顶部移动，点击右上角的图标切换置顶或锁定位置。在「设置 → 桌面与通知」调节背景透明度，也可右键点击小组件顶部打开设置。
- 点击日历日期查看当天待办，点击任务标题打开详情。在待办小组件可勾选、撤销完成或新建待办。
- 在「设置 → 主题色」可选择五款预设主题，或输入六位十六进制颜色。周计划和任务看板也随主题换色。左上角按钮可折叠或展开导航。左下角的齿轮可打开设置，导航折叠后仍可使用。
- 在任务列表点击「多选」，勾选待办后可以「移到清单」或「改日期」。批量改期适用于待完成的单次任务，保留原时段。移动循环待办会移动整个系列。
- 触屏左滑任务行可显示删除图标。点击删除后仍需确认。
- 点击任务行五角星旁边的番茄钟图标，可开始关联到该待办的 25 分钟专注。
- **Ctrl+N** 新建待办，**Ctrl+K** 全局搜索（也支持 Ctrl+F），**Esc** 关闭对话框。关闭主窗口默认保留在系统托盘，可在「设置」调整。

## 从源码构建

在源码目录运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1 -Package`，便携包输出到 `release\Biandan-Windows-x64-1.4.1.zip`。
