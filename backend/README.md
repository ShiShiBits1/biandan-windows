# 便单 MCP v0.4.6 体验版

用支持 Streamable HTTP 的 AI 客户端管理便单。首次在浏览器授权后，MCP 会自动续期。已有 v0.2 体验版的用户升级后需要完成一次离线授权。

## 启动和连接

1. 完整解压。Windows x64 可直接运行，Python 版需要 Python 3.10 或以上。
2. Windows 双击 `start-biandan-mcp.cmd`。Python 版运行 `python biandan_mcp.py --http`。保留共享服务的终端窗口。
3. Windows 双击 `copy-mcp-config.cmd`，Python 版运行 `python biandan_mcp.py --print-http-config`。把生成的 URL 和 Authorization 请求头粘贴到支持 Streamable HTTP 的 MCP 客户端。多个会话共用同一个本机服务。
4. 在客户端发「列出今天未完成的待办」。首次需要访问便单账号时，MCP 会打开浏览器。完成华为授权后，让 AI 再查一次。启动服务、加载连接器和调用 `biandan_help` 查看用法时无需授权。

使用 STDIO 的客户端也会等到首次调用云端工具才打开授权页。该模式由客户端启动便单，进程重启后可能需要重新授权。

## 可以试什么

新建和编辑待办时，备注可以输入普通文本，也可以传入便单 7.1.1 支持的 Markdown 源码。MCP 会保留备注的换行和格式标记，编辑备注时会保留已有的子任务和附件。

| 对 AI 说 | 能做的事 |
| --- | --- |
| 「建一个阅读清单，把这三件事放进去」 | 新建、改名、换颜色或删除待办单，批量创建、编辑、移动或完成任务。 |
| 「预览批量删除这几条任务，我确认后再删」 | 一次提交全部选中的任务，MCP 自动分批。循环任务可指定删除范围，预览和删除结果都逐项返回。 |
| 「从下周起，每周一和周三晚上读书，持续到月底」 | 创建循环任务，读回完整规则，或预览规则修改会影响哪些未来实例。 |
| 「只把这周三这次读书改到周四」 | 将选中的循环实例改期，保留它的实例 ID 和原持续时间。 |
| 「刚才误完成了，撤销一下」 | 撤销完成、取消勾选、放弃或恢复某次执行、记录目标次数。 |
| 「把这件事的地点改成办公室，提前一小时提醒」 | 保存地点和 GCJ-02 坐标，添加、修改或关闭时间提醒。地点提醒的实际触发由有权限的鸿蒙客户端负责。 |
| 「看最近一周的习惯打卡，再补记昨天的 25 分钟专注」 | 查询习惯和执行历史，补打卡，增删改查专注记录，统计专注分钟数和番茄数。 |

删除任务和专注记录会同步到云端。循环任务可选本次、之后未完成的实例，或整个系列。删除待办单默认把其中的任务移到「未分类」。批量删除任务会自动分批，数量较多时需要等待更久。批量新增、修改和完成任务每次最多 20 项。各批量工具都按项目返回结果。

创建循环需要提供结束日期，一次最多生成 1000 条实例。「每周一」选自定义周规则并指定周一；按周的周期任务则每条实例覆盖一整周。可选的中国调休数据与原生端一致，覆盖 2024–2026。修改循环规则会保留截止日前、已完成、有进度或已放弃的实例。编辑已有进度的子任务时，可以就地改名、追加或从末尾删减。

用 `biandan_help` 指定工具名，可查看参数约束和调用示例。删除任务、删除待办单和修改循环规则都支持 `preview: true`。两个删除工具会列出受影响的实例或任务，循环修改预览会返回各类变更的数量。

## 自动续期

自动续期适用于共享 HTTP 模式。刷新令牌保存在运行 MCP 的设备上，Windows 使用当前用户的 DPAPI 加密，macOS 和 Linux 使用仅当前用户可读写的文件。OAuth Client Secret 由续期服务保管。业务请求仍由 MCP 直接发往便单云端。

华为刷新令牌通常有效 180 天。令牌仍有效时，重启服务和访问令牌过期都会自动刷新。华为确认刷新令牌已失效或授权被撤销时，MCP 会重新打开授权页。续期服务暂时不可用时稍后重试即可。

如要停止使用，关闭 MCP。需要换账号或清除本机授权时，先退出 MCP，再删除其状态目录里的 `huawei-refresh-*` 凭据文件。默认状态目录为 Windows 的 `%LOCALAPPDATA%\.biandan-mcp` 或 macOS/Linux 的 `~/.biandan-mcp`。
